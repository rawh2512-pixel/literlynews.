# Tahap dashboard admin Literly News

Folder ini disiapkan untuk konfigurasi CMS pada tahap berikutnya.

Penting: halaman GitHub Pages bersifat statis. Jangan membuat login admin hanya dengan password yang ditulis di JavaScript karena password dapat dibaca pengunjung.

Tahap berikutnya adalah menghubungkan CMS berbasis GitHub dengan autentikasi OAuth / GitHub App yang benar. Setelah konfigurasi autentikasi dipilih, admin dapat membuat artikel, mengunggah gambar, menyimpan draft, dan menerbitkan berita ke repository.
